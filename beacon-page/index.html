📋 Pre-Configured Config

Download the config file and place it at the path for your OS. This sets the relay address and the server key in one step.

⬇ Download RustDesk2.toml
Config paths by OS:
Linux → ~/.config/rustdesk/RustDesk2.toml
macOS → ~/Library/Preferences/RustDesk/RustDesk2.toml
Windows → %APPDATA%\RustDesk\config\RustDesk2.toml
Or from the terminal:
curl -sO https://beacon.primals.eco/RustDesk2.toml

🔧 Key Mismatch Fix

If a gate shows “Authentication failed - invalid key” in the relay logs:

  1. Stop RustDesk on the gate: sudo systemctl stop rustdesk
  2. Download the correct config: curl -sO https://beacon.primals.eco/RustDesk2.toml
  3. Copy to config dir: cp RustDesk2.toml ~/.config/rustdesk/
  4. Delete stale key state: rm -f ~/.config/rustdesk/RustDesk.toml
  5. Restart: sudo systemctl start rustdesk

The old RustDesk.toml caches a key_confirmed flag. If the server key changed or was never set correctly, this cache prevents re-verification. Deleting it forces a fresh key exchange.
